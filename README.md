# SpotUNITY

SpotUNITY helps students discover student organizations, scholarships, and internships based on their class standing, major, and preferences.

## What it does

- Filters opportunities using a student's profile and selected interests
- Displays matches in a dashboard with separate tabs
- Shows a summary of matches and the total listed amounts for matching scholarships
- Links to opportunity pages when a URL is available

Scholarship results are potential matches. Students should check each opportunity's full eligibility requirements before applying.

## Built with

Python, Streamlit, pandas, and Google Sheets.

## Run locally

1. Download or clone this repository.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the app:

   ```bash
   streamlit run app.py
   ```

The app loads its opportunity data from Google Sheets, so an internet connection is required.
